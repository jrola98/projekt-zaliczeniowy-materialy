## Repozytorium i opis projektu
 
### Co zrobić
- Utworzyć repozytorium na GitHubie
- Dodać ten plik `README.md` z opisem projektu
- Wykonać kolejne diagramy i trzymać się schematu folderów oraz organizacji pracy
- Kolejność diagramów jak w wymaganiach.
- Zrobić pełną dokumentację
- Utworzenie projektu, który odpowiada dokumentacji

## Uwagi do diagramów.

1. Tworzymy przypadki użycia z opisu i pomysłu na projekt.
2. Diagram aktywności tworzymy na podstawie przypadków użycia. (1 przypadek użycia = 1 diagram aktywności)
3. Diagram sekwencji jest tworzony z diagramu aktywności, ale bierzemy pod uwagę tylko ścieżkę z powodzeniem. (1 diagram aktywności = 1 diagram sekwencji)
4. Diagram klas jeśli projekt jest obiektowy lub wykaz skryptów z funkcjami.
